# DAMFlotte CLD - App Store Deployment Guide

## Quick Start (MacBook)

```bash
cd apps/driver-mobile

# Step 1: Generate native platform directories
chmod +x setup_native.sh
./setup_native.sh

# Step 2: Configure credentials (see sections below)

# Step 3: Deploy
./deploy.sh all     # Both stores
./deploy.sh ios     # TestFlight only
./deploy.sh android # Play Store only
```

## iOS (Apple App Store / TestFlight)

### Prerequisites
- Xcode installed
- Apple Developer account ($99/year)
- App created in App Store Connect

### Configuration

1. Edit `ios/fastlane/Appfile`:
```ruby
app_identifier("ci.damflotte.driver")
apple_id("your-email@example.com")
itc_team_id("YOUR_ITC_TEAM_ID")
team_id("YOUR_TEAM_ID")
```

2. Open `ios/Runner.xcworkspace` in Xcode:
   - Set your Team in Signing & Capabilities
   - Verify Bundle Identifier matches `ci.damflotte.driver`
   - Enable automatic code signing

3. Deploy:
```bash
./deploy.sh ios
```

### Finding Your Team IDs
- App Store Connect > Users and Access > Team ID in sidebar
- Or run: `fastlane produce` and follow prompts

## Android (Google Play Store)

### Prerequisites
- Android SDK installed
- Google Play Console account ($25 one-time)
- App created in Google Play Console

### Configuration

1. **Create Service Account Key:**
   - Google Play Console > Settings > API access
   - Create service account (or link existing)
   - Grant "Release manager" permission
   - Download JSON key
   - Save as: `android/fastlane/play-store-key.json`

2. **Signing key** is auto-generated by `setup_native.sh`
   - Stored in `android/keystore/upload-keystore.jks`
   - Config in `android/key.properties`
   - **Change default passwords before production!**

3. Deploy:
```bash
./deploy.sh android
```

### Manual APK Upload (Alternative)
If service account is not set up:
```bash
flutter build apk --release
# Upload build/app/outputs/flutter-apk/app-release.apk
# via Google Play Console > Testing > Internal testing
```

## Build Numbers

Each deployment should have a unique build number. Bump it with:
```bash
./deploy.sh bump
```

This increments the `+N` suffix in `pubspec.yaml` version field.

## Troubleshooting

| Issue | Fix |
|-------|-----|
| `No signing certificate` | Open Xcode, set Team in Signing |
| `Provisioning profile not found` | Enable automatic signing in Xcode |
| `Google Play upload fails` | Verify service account has Release Manager role |
| `Build number already exists` | Run `./deploy.sh bump` before deploying |
| `CocoaPods not installed` | `brew install cocoapods` then `cd ios && pod install` |
